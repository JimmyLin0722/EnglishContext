# CT-25 紀錄：Part 5 題目 id 穩定性快照與檢查（V-P5-08）

依據：tasks.json v0.9 CT-25；契約 v0.15 README §7.4 V-P5-08、§9.8 DS-37；data-schema.ts `Part5Question.id`（v0.15 註解）；architecture.md v0.10 §7.21.6（SD-FB-61）。涵蓋 US-45、AC-45-07。

| 檔案 | 內容 |

| `src/data/_tools/validate.mjs` | 新增 V-P5-08 檢查（規則代號 V-P5-08、V-P5-08W、V-P5-08N 加入規則清單與說明表）、`--update-snapshot`、`--accept <id>`；說明文字（`--help`）補上規則與選項。其他檢查行為不變 |

## 2. 規則

| 項目 | 內容 |
| :--- | :--- |
| 指紋 | Node 內建 `crypto` SHA-256，取前 16 個 hex；對象字串先 NFC → trim → 連續空白壓成 1 個 → 小寫 |
| 每題指紋 | `s` = `sentence`；`a` = `options[correctIndex]` |
| 執行條件 | `--stage final` 且載入 `part5.js`（`--all` 或 `--file part5.js`）且快照檔存在；快照不存在 → 印出提示並列在「略過的規則」；`skeleton`／`partial` 階段略過 |
| 快照位置 | 固定讀寫專案的 `src/data/_records/part5-ids.json`，**不隨 `--data` 改變**（可用 `--data` 指向修改過的副本，與已交付的快照比對） |
| 快照 id 仍在題庫，`s`、`a` 皆不同 | 錯誤 V-P5-08（id 改號或改指另一題） |
| 快照 id 仍在題庫，只有一個不同 | 警告 V-P5-08W（請確認為錯字修正） |
| 快照 id 不在題庫 | 資訊 V-P5-08（刪題，id 不得重用） |
| 題庫 id 不在快照 | 警告 V-P5-08N（新題，交付後請更新快照） |
| 快照格式錯誤（無法解析、指紋不是 16 位小寫 hex 等） | 錯誤 V-P5-08 |
| 題庫陣列順序 | 不影響結果（以 id 比對） |

## 3. 快照更新選項

| 選項 | 行為 |
| :--- | :--- |
| `--update-snapshot` | 只**新增**快照沒有的 id；不刪除、不覆寫既有項目；快照不存在時建立（`meta.createdBy` CT-25、`source`、`createdAt`）；`meta.count` = 快照 id 數。id 重複或 sentence／正解格式錯誤的題目不加入並報錯 |
| `--accept <id>[,<id>…]` | 以目前內容覆寫指定 id 的指紋；id 不在題庫、重複或格式錯誤 → 錯誤，整批不寫入 |
| 共同 | 只寫 `src/data/_records/part5-ids.json`；以 id 排序、每題一行；寫入後同一次執行即以新快照檢查 |

## 5. 日後維護方式

| 情況 | 做法 |
| :--- | :--- |
| 修正某題錯字（題意與正解不變），出現 V-P5-08W | 人工確認後執行 `node src/data/_tools/validate.mjs --all --stage final --accept <id>`，快照覆寫該 id |
| 出現錯誤 V-P5-08 | 代表既有 id 改號或改指另一題：還原 id 對應；若確定是同一題的大幅修訂（題意、正解都相同），才以 `--accept <id>` 接受 |
| 新增題目 | 使用從未用過的 id（目前最大 p5-200，下一個為 p5-201 起；已刪除的 id 也不可再用）；交付後執行 `--update-snapshot` 加入快照，V-P5-08N 即消失 |
| 刪除題目 | 不改快照（快照保留已刪 id，作為「不得重用」的紀錄），只會出現資訊 |
| 調整題目順序 | 不需處理（以 id 比對） |
| 禁止 | 手動刪除快照項目或重建整份快照（會失去改號偵測能力） |
