# BUG-004 交付檔 `dist/english-master-track.html` 在建置後被直接修改，與原始碼及部署目錄 `dist/site/index.html` 不一致

> 第 7 輪驗收期間（2026-11-04 11:24:16）發現。QA 在 10:59～11:03 確認交付檔與原始碼重建結果逐位元組相同（TC-S09 通過），之後交付檔被修改；QA 本輪所有程式只讀取 `dist/`，不寫入（`tests/` 內無寫入 `DIST` 的程式碼）。修改不是經 `npm run build` 產生：`src/` 無對應變更、BUILD_ID 未改變。

## 重現步驟

| 步 | 操作 |
| :--- | :--- |
| 1 | `node tools/build.mjs --out <暫存>/rebuilt.html`（不改任何原始碼） |
| 2 | 比對 `<暫存>/rebuilt.html`、`dist/site/index.html`、`dist/english-master-track.html` 的 SHA-256 |
| 3 | 把 `rebuilt.html` 的 CR 去掉後與 `dist/english-master-track.html` 做 `diff` |
| 4 | `node tests/static/static-check.mjs`（TC-S09）、`node tests/e2e/e2e-version.mjs`（TC-42-02、TC-42-04a） |

## 可能原因（選填）

建置後有人直接編輯 `dist/english-master-track.html`（字串 `contact :` 冒號前有空格、換行被編輯器改為 LF，皆非建置產物的格式）。QA 無法判斷是否為人類有意的新需求：

- 若是人類要的新文字（聯絡 email、更新提示改為「請更新版本」）：需修改 PRD（AC-36-03、US-23）→ 契約／設計 → 改 `src/app/core/pwa.js`、`src/app/views/sources-page.js` 後重新建置，依 CLAUDE.md 須停下來問人類。
- 若不是：由 pg-frontend 依 FE-76 執行 `npm run build` 重新產生 `dist/`（原始碼未變，結果會與 `dist/site/index.html` 相同），QA 再複驗 TC-S09、TC-42-02、TC-42-04a。
